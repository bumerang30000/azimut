# Азимут — технический разбор по тикеру

Вводите тикер и получаете готовый разбор: волны Эллиотта (с согласованием таймфреймов), сетку Фибоначчи, уровни, ордер-блоки, пулы ликвидности, карту ликвидаций (крипто), скользящие средние, три сценария с вероятностями, новостной фон и разметку прямо на графике. Рынок (крипта / акции / Мосбиржа) и таймфреймы 4Ч, 1Д, 1Н определяются автоматически.

Примеры тикеров: BTC, ETH, SOL, TON · AAPL, NVDA, TSLA · SBER, GAZP, LKOH · GC=F (золото), ^GSPC (S&P 500), EURUSD=X.

## Как устроено
| Что | Откуда | Ключ / оплата |
|---|---|---|
| Крипта | Binance market-data (`data-api.binance.vision`), резерв Bybit — напрямую из браузера | не нужны |
| Акции, индексы, валюты, сырьё | Yahoo Finance через функцию `api/chart` (библиотека `yahoo-finance2`, проходит cookie/crumb) | не нужны |
| Мосбиржа | ISS MOEX напрямую, резерв — `api/proxy` | не нужны |
| Новости | `api/news`: Yahoo Finance + Google News RSS | не нужны |
| Открытый интерес, фандинг, лонг/шорт (крипто) | Binance Futures, резерв Bybit — напрямую из браузера | не нужны |
| Индекс страха и жадности | alternative.me | не нужны |

Хостинг — Vercel Hobby (бесплатно, для личного некоммерческого использования). Ответы функций кэшируются на CDN, поэтому лимит в 1 млн вызовов в месяц с большим запасом.

## Методика
- **Сценарии** строятся от реальных уровней: горизонтальные зоны, Фибоначчи текущего плеча, ордер-блоки, пулы ликвидности, кластеры ликвидаций, SMA 200. Цели выбираются по силе совпадения и достижимости за горизонт.
- **Вероятности** — Монте-Карло (толстые хвосты, EWMA-волатильность, небольшой дрейф от суммарного сигнала): какая цель будет достигнута первой за горизонт (4Ч — неделя, 1Д — ~1,5 месяца, 1Н — квартал).
- **Отмена** — ближайшая структура против сценария, а не край всего волнового счёта.
- **Волны** считаются в лог-шкале; младший таймфрейм согласуется со старшим.
- **Карта ликвидаций** — оценка по приросту открытого интереса Binance за ~30 дней с раскладкой по плечам 5–100×.

## Публикация
Репозиторий подключён к Vercel: любой коммит в `main` публикуется автоматически.

## Вариант без сервера
Откройте `index.html` как файл. Крипта и Мосбиржа работают сразу, акции — через публичные шлюзы и могут не отвечать.

Материал носит информационный характер и не является индивидуальной инвестиционной рекомендацией.
